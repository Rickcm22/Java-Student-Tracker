# 🎓 Java Student Tracker
> **Status:** Operational  
> **Environment:** Java (Console Application)  
> **Origin:** Software Engineering Project

## ⚡ Overview
**Java Student Tracker** es un sistema de consola desarrollado en Java para la gestión eficiente de registros estudiantiles. El proyecto implementa una arquitectura básica de manejo de datos mediante objetos, encapsulamiento y colecciones dinámicas.

## 🛠️ Technical Specs & Features
* **Registro:** Permite agregar estudiantes con un ID único autoincremental, nombre y carrera.
* **Consulta:** Listado completo de estudiantes registrados y búsqueda optimizada por ID específico.
* **Eliminación:** Borrado seguro de registros del sistema mediante identificadores únicos.
* **Estructura:** Uso de `ArrayList` para almacenamiento dinámico y modelado de entidades mediante clases internas estáticas.
